# E4–E6/v1: half-periods and real dilation

The targets are E4, E5 and E6, each version 1, in **Quaternionic elliptic
functions**. The [source snapshot](E4-E6-source.json) retains the accepted
article, its exact revision and SHA-256, and the lattice and series conventions.
The proofs build on the independently pinned E3 delivery and reuse mathlib.

## Definitions and correspondence

| Written object | Lean counterpart |
| --- | --- |
| Full-rank L⊂ℍ | The unchanged `L : Submodule ℤ ℍ`, `[DiscreteTopology L]`, `[IsZLattice ℝ L]`. Any real quaternion basis gives these instances. |
| wp_L,j, ζ_L, η_L | The unchanged `elliptic L j`, `zeta L` and `zetaQuasiperiod L`. E1/E2/E3 already establish their analytic properties and characterize η uniquely. |
| ω/2 and 2ζ_L(ω/2) | `(2 : ℝ)⁻¹ • (w : ℍ)` and `(2 : ℝ) • zeta L ...`. The scalar action is ordinary multiplication by a real number. `w : L` supplies the lattice-membership condition. |
| The real differential is zero | `HasFDerivAt (elliptic L j) (0 : ℍ →L[ℝ] ℍ) ...`. This asserts existence of the actual derivative with value zero. `elliptic_fderiv_halfPeriod` also states the equality using `fderiv`. |
| All four real partial derivatives | `∀ μ : Fin 4, coordPartial μ ... = 0`, including μ=0 for time. `j : Fin 3` represents the article's spatial labels 1,2,3. |
| Positive real scale a | `a : ℝ`, `ha : 0 < a`; `ha.ne'` is the derived proof that a≠0. `(a ^ 4)⁻¹` and `(a ^ 3)⁻¹` are a⁻⁴ and a⁻³. |
| aL | `dilatedLattice L a ha.ne'`. Its exact membership characterization is shown below. Discreteness and full rank are proved automatically from the original lattice's hypotheses. |
| aω as an element of aL | `latticeDilationEquiv L a ha.ne' w`. Its value in ℍ is proved to be exactly `a • (w : ℍ)`. |

The only new mathematical construction is the dilation of a lattice. It uses
mathlib's pullback under the inverse real linear equivalence:

```lean
def realDilation (a : ℝ) (ha : a ≠ 0) : ℍ ≃L[ℝ] ℍ :=
  (LinearEquiv.smulOfNeZero ℝ ℍ a ha).toContinuousLinearEquiv

def dilatedLattice (L : Submodule ℤ ℍ) (a : ℝ) (ha : a ≠ 0) : Submodule ℤ ℍ :=
  ZLattice.comap ℝ L (realDilation a ha).symm.toLinearMap
```

The following proved identities make the direction of this pullback inspectable:

```lean
q ∈ dilatedLattice L a ha ↔ ∃ x ∈ L, a • x = q
 a • q ∈ dilatedLattice L a ha ↔ q ∈ L
(latticeDilationEquiv L a ha w : ℍ) = a • (w : ℍ)
```

They are `mem_dilatedLattice`, `smul_mem_dilatedLattice` and
`latticeDilationEquiv_apply`. The second identity also verifies that aq is off
aL whenever q is off L. The nonzero-index equivalence used in the series is
just the restriction of this same lattice equivalence.

## Exact statements

In namespace `MathResearch.Fueter`, with
`(L : Submodule ℤ ℍ) [DiscreteTopology L] [IsZLattice ℝ L]`:

```lean
theorem E4_v1 (w : L) (hw : (2 : ℝ)⁻¹ • (w : ℍ) ∉ L) :
    zetaQuasiperiod L w = (2 : ℝ) • zeta L ((2 : ℝ)⁻¹ • (w : ℍ))
```

E4 retains the essential hypothesis that the half-period is not itself a lattice
point. It evaluates the existing, uniquely characterized quasiperiod map.

```lean
theorem E5_v1 (j : Fin 3) (w : L) (hw : (2 : ℝ)⁻¹ • (w : ℍ) ∉ L) :
    HasFDerivAt (elliptic L j) (0 : ℍ →L[ℝ] ℍ) ((2 : ℝ)⁻¹ • (w : ℍ)) ∧
    ∀ μ : Fin 4, coordPartial μ (elliptic L j) ((2 : ℝ)⁻¹ • (w : ℍ)) = 0
```

E5 states existence of the zero real derivative as well as all four zero
coordinate derivatives. This avoids interpreting the default value of
`fderiv` at a nondifferentiable point as a stationary derivative.

```lean
theorem E6_v1 (a : ℝ) (ha : 0 < a) (j : Fin 3) (q : ℍ) (hq : q ∉ L) (w : L) :
    elliptic (dilatedLattice L a ha.ne') j (a • q) = (a ^ 4)⁻¹ • elliptic L j q ∧
    zeta (dilatedLattice L a ha.ne') (a • q) = (a ^ 3)⁻¹ • zeta L q ∧
    zetaQuasiperiod (dilatedLattice L a ha.ne') (latticeDilationEquiv L a ha.ne' w) =
      (a ^ 3)⁻¹ • zetaQuasiperiod L w
```

E6 includes all three scaling laws with the written positive-scale, off-lattice
and arbitrary-period quantifiers. The instance showing that aL is again a
full-rank lattice is supplied by the proof library, not an extra premise.

The author compared the half-period exclusion, numerical factors, derivative
existence, time coordinate, scaling direction, weights and quasiperiod argument
with the retained written statements. This correspondence assessment is separate
from the Lean proof check. Each small definition comparison is available for
readers to inspect without a visitor approval state.

## Proof and mathlib reuse

[HalfPeriods.lean](../MathResearch/Fueter/HalfPeriods.lean) proves E4 by applying
E3's increment formula at −ω/2 and using zeta oddness. For E5, mathlib's Fréchet
chain rule differentiates E2's evenness identity, proving that the full real
differential is odd. Its previously verified periodicity identifies the values
at ω/2 and −ω/2, making the differential zero. E1 supplies differentiability.

[LatticeDilation.lean](../MathResearch/Fueter/LatticeDilation.lean) uses mathlib's
`LinearEquiv.smulOfNeZero`, finite-dimensional continuity, `ZLattice.comap` and
`ZLattice.comap_equiv`. Mathlib transports both discreteness and full real span.

[EllipticDilation.lean](../MathResearch/Fueter/EllipticDilation.lean) uses F2 for
the kernel's weights −3 and −4. `kernel_fderiv_smul_apply` proves
`dG_(ab)[aq] = a⁻³ dG_b[q]`, scaling both the basepoint and the argument. Mathlib's
bijection-invariance of infinite sums and commutation with real scalar
multiplication then reindex the intact E-C1 and E-C2 brackets. Convergence is
already established by E1/E3 for the original and transported lattices. Finally,
the quasiperiod law follows by taking a zeta difference at an off-lattice
basepoint; the result applies to the uniquely characterized η, independently
of either lattice's chosen construction basepoint.

All earlier mathematical source modules and dependency pins are unchanged.
There are no additional axioms or assumed analytic conclusions.
