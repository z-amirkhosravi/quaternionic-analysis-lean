# E1/v2 and E2/v2: quaternionic elliptic functions

The targets are the two version-2 propositions in
[Quaternionic elliptic functions](https://z-amirkhosravi.github.io/homepage/math-2.0/quaternionic-analysis/elliptic-functions.html#e1).
The [source snapshot](E1-E2-source.json) retains their written statements and
proofs, the lattice conventions, E-C1/version 1, and the article fingerprint.
These proofs extend F1/F2 and N2/N3 without changing their mathematical sources,
Lean version or mathlib pin.

## The construction and small correspondence checks

`elliptic L j q` is defined literally as

```lean
kernelSpatialPartial j q + ∑' a : {a : L // a ≠ 0},
  (kernelSpatialPartial j (q + (a.1 : ℍ)) - kernelSpatialPartial j (a.1 : ℍ))
```

The parentheses remain one summand. The proof never separates the two
borderline divergent sums. `elliptic_eq_tsum` proves an equivalent indexing by
all lattice points, with the leading term assigned index zero.

| Written object | Lean counterpart and meaning |
| --- | --- |
| Full-rank real quaternion lattice L | `L : Submodule ℤ ℍ`, `[DiscreteTopology L]`, `[IsZLattice ℝ L]`. Mathlib supplies discreteness and full real span; arbitrary real bases give these instances. |
| G and G_j | The unchanged F1 `kernel` and F2 `kernelSpatialPartial j`. `j : Fin 3` uses 0,1,2 for the written spatial indices 1,2,3. |
| Real derivatives | `coordPartial μ` is `fderiv ℝ` applied to the quaternion basis vector μ. `μ : Fin 4` includes the time coordinate at 0. `iteratedPartial l` applies any finite ordered list; the empty list is the original function. |
| Each E-C1 summand | `regularizedJet j [] a q` is G_j(q+a) minus G_j(a) for a≠0, and exactly G_j(q) for a=0. This last case is explicit and does not assume any value of the singular kernel derivative at zero. |
| Differentiated summands | `kernelJet j l = iteratedPartial (l ++ [j.succ]) kernel`. For nonempty l, `regularizedJet` is this derivative at q+a, with no subtracted constant. `elliptic_summand_iteratedPartial` proves it is the actual derivative of the original summand on the stated domain. |
| Left and right regularity | The unchanged `TwoSidedRegularOn f U` asserts `ContDiffOn ℝ ∞ f U` and vanishing of both constant-coefficient Fueter operators. Smoothness prevents default zero derivatives at nondifferentiable points from witnessing regularity. |

For each list l, E1 states absolute convergence of the actual differentiated
summands, uniform convergence of their finite-subset sums on every compact
subset of H\L, and `HasSumLocallyUniformlyOn` with limit the actual derivative
`iteratedPartial l (elliptic L j)`. Thus it proves both derivative interchange
and convergence, at every real order and without fixing an enumeration.
The empty list gives the undifferentiated series. Every four-coordinate
multi-index is a particular list; the statement check verifies that specialization.

The pole conclusion quantifies over every `w : L`, including zero. It supplies
an open set U containing w and a function r that is smooth and both left and
right regular on U, with
`r q = elliptic L j q - kernelSpatialPartial j (q - w)`
for q in U outside L. This is an extension through the pole itself. The
construction removes index -w, uses the remaining series on its open pole-free
domain, and subtracts the one constant left by that regularized term.

E2 quantifies over every q outside L and every lattice period w, proving
both `elliptic L j (-q) = elliptic L j q` and
`elliptic L j (q+w) = elliptic L j q`. No genericity, rationality or choice of
lattice basis is imposed.

## Exact final statements

Both declarations are in `MathResearch.Fueter`, with parameters
`(L : Submodule ℤ ℍ) [DiscreteTopology L] [IsZLattice ℝ L]`.

```lean
theorem E1_v2 (j : Fin 3) :
    (∀ l : List (Fin 4), ∀ q : ℍ, q ∉ L →
      Summable (fun a : L => ‖iteratedPartial l (regularizedJet j [] (a : ℍ)) q‖)) ∧
    (∀ l : List (Fin 4), ∀ K : Set ℍ, IsCompact K → K ⊆ (L : Set ℍ)ᶜ →
      TendstoUniformlyOn (fun s : Finset L => fun q =>
        ∑ a ∈ s, iteratedPartial l (regularizedJet j [] (a : ℍ)) q)
        (iteratedPartial l (elliptic L j)) atTop K) ∧
    (∀ l : List (Fin 4), HasSumLocallyUniformlyOn
      (fun a : L => iteratedPartial l (regularizedJet j [] (a : ℍ)))
      (iteratedPartial l (elliptic L j)) (L : Set ℍ)ᶜ) ∧
    TwoSidedRegularOn (elliptic L j) (L : Set ℍ)ᶜ ∧
    (∀ w : L, ∃ U : Set ℍ, IsOpen U ∧ (w : ℍ) ∈ U ∧ ∃ r : ℍ → ℍ,
      TwoSidedRegularOn r U ∧ ∀ q ∈ U, q ∉ L →
        r q = elliptic L j q - kernelSpatialPartial j (q - (w : ℍ)))

theorem E2_v2 (j : Fin 3) :
    ∀ q : ℍ, q ∉ L → ∀ w : L,
      elliptic L j (-q) = elliptic L j q ∧
      elliptic L j (q + (w : ℍ)) = elliptic L j q
```

## Proof dependencies and mathlib reuse

- [SeriesCalculus.lean](../MathResearch/Fueter/SeriesCalculus.lean) proves a
  local normal-convergence criterion and a smooth-series theorem indexed by
  ordered coordinate derivatives. It uses mathlib's operator-norm estimate
  `Module.Basis.opNorm_le`, finite-dimensional smoothness criteria,
  `hasFDerivAt_of_tendstoLocallyUniformlyOn`, and continuous-linear maps of sums.
- [EllipticEstimates.lean](../MathResearch/Fueter/EllipticEstimates.lean) combines
  F2 with mathlib's mean-value theorem on a closed ball. For bounded q and large
  lattice a, the intact bracket is bounded by C R |a|^-5; derivative order m≥1
  has decay |a|^(-4-m). N2's mathlib-based lattice p-series machinery supplies
  summable majorants. Finite exceptional lattice terms are handled explicitly
  by cofinite normal-convergence bounds.
- [EllipticRegularity.lean](../MathResearch/Fueter/EllipticRegularity.lean) treats
  arbitrary subseries on their open domains. It proves smoothness, derivative
  identities, and both Fueter equations, commuting the continuous linear
  contractions with convergent sums. This also handles the subseries with
  one singular term removed.
- [Elliptic.lean](../MathResearch/Fueter/Elliptic.lean) identifies the exact E-C1
  definition, proves the statements for actual ordered derivatives, and supplies
  the pole extensions and `E1_v2`.
- [EllipticPeriodicity.lean](../MathResearch/Fueter/EllipticPeriodicity.lean)
  proves parity by negation of indices and periodicity of the derivative
  series by translation. Mathlib's countable-complement connectedness theorem
  applies in real dimension four. Its zero-derivative theorem makes each
  period increment constant; evenness then forces this constant to vanish.

No analytic conclusion is an unproved theorem parameter. The formalization
author compared the exact hypotheses, definitions, signs, domain, derivative
quantifiers and pole-extension statement with the saved written source. This
is a correspondence assessment, not an independent review, visitor approval
state or human-gated workflow. Readers can inspect each definition and theorem.
