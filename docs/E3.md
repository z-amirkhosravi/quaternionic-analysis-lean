# E3/v2: the zeta function and its quasiperiods

The target is E3, version 2, in the published **Quaternionic elliptic functions**
article. [The source snapshot](E3-source.json) retains the exact accepted article,
its revision and SHA-256, including the E-D1 lattice setup and the E-C2 construction.
The proof is for an arbitrary full-rank real quaternionic lattice.

## Small definition comparisons

| Written object | Lean counterpart |
| --- | --- |
| Full-rank L⊂ℍ | `L : Submodule ℤ ℍ`, `[DiscreteTopology L]`, `[IsZLattice ℝ L]`. These are the same mathlib hypotheses used for E1/E2. An arbitrary real basis supplies them; the statement check verifies this. |
| q=t+x₁i+x₂j+x₃k | Mathlib's `Quaternion ℝ`, written `ℍ`. `coordinateBasis` is its real basis `1,i,j,k`; the real indices are `Fin 4`, starting with time at 0. |
| G(q)=conj(q)/‖q‖⁴ | The unchanged `kernel`, with `kernel_eq` identifying its norm formula. |
| dGₐ[q] | Mathlib's real Fréchet differential, `fderiv ℝ kernel a q`. `kernel_differential_coordinates` proves it is the sum of the four real coordinates of q times the corresponding partial derivatives. |
| ζ_L | `zeta L`, the literal leading kernel plus the sum over nonzero lattice points of the intact Taylor brackets, shown below. Quaternion addition is commutative, so q+a and a+q agree. |
| ∂xⱼζ_L=wp_L,j | `zeta_spatialPartial`. `j : Fin 3` uses 0,1,2 for the article's 1,2,3, and `j.succ : Fin 4` selects the corresponding spatial coordinate. `elliptic` is the unchanged E-C1 series. |
| Both regularities | The unchanged `TwoSidedRegularOn`: real smoothness and vanishing of both actual left and right Fueter differential operators. |
| Additive η_L:L→ℍ | Mathlib's `L →+ ℍ`, an `AddMonoidHom`. `zetaQuasiperiod` constructs one, `zeta_add` gives its identity at every off-lattice point, and `zeta_unique_quasiperiod` proves uniqueness among all such additive maps. |

```lean
def zeta (L : Submodule ℤ ℍ) (q : ℍ) : ℍ :=
  kernel q + ∑' a : {a : L // a ≠ 0},
    (kernel (q + (a.1 : ℍ)) - kernel (a.1 : ℍ) - fderiv ℝ kernel (a.1 : ℍ) q)
```

For convergence statements it is convenient to include the leading term as the
zero lattice index. The two small identities `zetaJet_zero` and `zetaJet_nil` say

```lean
zetaJet [] 0 q = kernel q
zetaJet [] a q = kernel (q + a) - kernel a - fderiv ℝ kernel a q  -- a ≠ 0
```

`zeta_eq_jetSum` proves that summing these terms is exactly `zeta L`.
No subtraction is split into separately summed borderline series. Removing or
adding the single leading term does not change absolute or local uniform
convergence; off the lattice this term and every derivative are smooth by F1.

`iteratedPartial l` applies actual real coordinate derivatives in the order
specified by a finite list `l : List (Fin 4)`; `[]` is the function itself.
Consequently the convergence clauses include order zero, time derivatives,
all mixed derivatives, and every order, without a bound. The separate statement
check also applies them to every real multi-index `α : Fin 4 → ℕ` using the
unchanged `multiIndexPartial` definition.

The full `zetaJet` definition records the differentiated brackets: order zero
subtracts the affine Taylor polynomial, order one subtracts its constant
partial derivative, and at orders at least two no subtraction remains.
`zeta_summand_iteratedPartial` proves that these expressions are the actual
iterated derivatives, rather than assuming that interpretation.

## Exact statement

In namespace `MathResearch.Fueter`, with
`(L : Submodule ℤ ℍ) [DiscreteTopology L] [IsZLattice ℝ L]`:

```lean
theorem E3_v2 :
    (∀ l : List (Fin 4), ∀ q ∉ L,
      Summable (fun a : L => ‖iteratedPartial l (zetaJet [] (a : ℍ)) q‖)) ∧
    (∀ l : List (Fin 4), ∀ K : Set ℍ, IsCompact K → K ⊆ (L : Set ℍ)ᶜ →
      TendstoUniformlyOn (fun s : Finset L => fun q =>
        ∑ a ∈ s, iteratedPartial l (zetaJet [] (a : ℍ)) q)
        (iteratedPartial l (zeta L)) atTop K) ∧
    (∀ l : List (Fin 4), HasSumLocallyUniformlyOn
      (fun a : L => iteratedPartial l (zetaJet [] (a : ℍ)))
      (iteratedPartial l (zeta L)) (L : Set ℍ)ᶜ) ∧
    Function.Odd (zeta L) ∧
    TwoSidedRegularOn (zeta L) (L : Set ℍ)ᶜ ∧
    (∀ j : Fin 3, ∀ q ∉ L, coordPartial j.succ (zeta L) q = elliptic L j q) ∧
    (∃! η : L →+ ℍ, ∀ w : L, ∀ q : ℍ, q ∉ L →
      zeta L (q + (w : ℍ)) - zeta L q = η w)
```

This bundles norm summability, uniform convergence on every compact subset,
local uniform convergence to the actual derivatives, oddness, both regularities,
the spatial derivative identities, and existence and uniqueness of the additive
quasiperiod map. `Function.Odd` proves the total-function parity identity for all
q, which includes the written off-lattice statement. Smoothness and derivative
identities are asserted only off L.

The formalization author compared the lattice hypotheses, full real differential,
subtraction signs, coordinate indices, derivative orders, left/right operator
order, domain and uniqueness quantifiers with the retained E3/v2 source. This is
a correspondence assessment, separate from the Lean proof check. Each reader
can inspect these small comparisons; there is no visitor approval state.

## Proof and mathlib reuse

- [ZetaSummands.lean](../MathResearch/Fueter/ZetaSummands.lean) defines the
  Taylor jets and proves their actual Fréchet/coordinate derivatives. It reuses
  F1/F2 and mathlib's chain rule, linear differentials and finite-dimensional
  operator norm bound.
- [ZetaEstimates.lean](../MathResearch/Fueter/ZetaEstimates.lean) applies
  mathlib's mean-value bound on convex balls twice. First derivative differences
  have decay ‖a‖⁻⁵; integrating that estimate along a segment controls the
  original Taylor remainder. Higher derivatives have decay ‖a‖⁻³⁻ᵐ.
  The existing mathlib-based lattice p-series theorem supplies summable bounds.
- [Zeta.lean](../MathResearch/Fueter/Zeta.lean) reuses the E1 smooth-series
  machinery, based on mathlib's locally uniform derivative-limit theorem,
  to justify termwise differentiation. Continuous linear maps pass the two
  Fueter contractions through the convergent derivative sum. A spatial first
  derivative agrees term by term with E-C1.
- [ZetaQuasiperiods.lean](../MathResearch/Fueter/ZetaQuasiperiods.lean)
  reindexes intact brackets by a↦−a for oddness. E2 and left regularity make all
  four real derivatives of a lattice increment zero. Mathlib's constant-function
  theorem on a connected open set, with the previously proved connectedness of
  ℍ∖L, makes the increment independent of q. Splitting two successive increments
  proves additivity; evaluation at any off-lattice point proves uniqueness.

The arbitrary basepoint in `zetaBasepoint` only constructs the map.
`zeta_increment_const` proves independence before that choice is made. No
convergence, smoothness, regularity, connectedness or quasiperiod conclusion is
an extra hypothesis of `E3_v2`.
