# N1/v2: coefficients of the regular part at zero

The target is Proposition N1, version 2, in
[From lattice sums to number theory](https://z-amirkhosravi.github.io/homepage/math-2.0/quaternionic-analysis/directions.html#n1).
The [source snapshot](N1-source.json) retains the precise statement, N-C1,
the spatial-index convention and lattice setup, with article fingerprints.

For a full-rank quaternionic lattice L, a spatial index j, and any smooth
extension h_j near zero of wp_{L,j}−G_j, the statement is

> ∂^μ h_j(0) = E_{μ+ε_j}(L), for every spatial multi-index with |μ|≥1.

These are derivatives themselves, without factorial factors. The resulting
coefficient has order |μ|+1≥2, so its series is absolutely convergent by N2.

## Definitions and correspondence

| Written object | Lean counterpart |
| --- | --- |
| Full-rank L⊂H | `L : Submodule ℤ ℍ`, `[DiscreteTopology L]`, `[IsZLattice ℝ L]`, unchanged from N2/E1. Arbitrary real quaternion bases give these instances. |
| G_j and wp_{L,j} | The unchanged `kernelSpatialPartial j` and literal bracketed E-C1 definition `elliptic L j`. `j : Fin 3` uses 0,1,2 for the written indices 1,2,3. |
| Smooth extension h_j near 0 | A function `h`, open set `U` containing zero, `ContDiffOn ℝ ∞ h U`, and equality with `elliptic L j − kernelSpatialPartial j` at off-lattice points of U. These are the defining conditions of the object in N1. |
| Spatial μ and ∂^μ | `μ : Fin 3 → ℕ` and `multiIndexPartial (spatialMultiIndex μ)`. The unchanged `spatialMultiIndex` inserts zero in the time coordinate. |
| ε_j | Mathlib's `Pi.single j 1`, a function with value one at j and zero elsewhere. `sum_spatial_add_single` proves that it increases the total order by one. |
| E_{μ+ε_j}(L) | The unchanged `eisensteinCoefficient L (μ + Pi.single j 1)`, a sum over nonzero lattice points of the actual higher kernel derivative. `N1_coefficient_summable` separately proves norm summability. |

The canonical extension is `ellipticRegularPart L j`, the E1 subseries with
its zero-index pole removed. Its explicit formula, proved in
`ellipticRegularPart_eq`, is

```lean
∑' a : {a : L // a ≠ 0},
  (kernelSpatialPartial j (q + (a.1 : ℍ)) - kernelSpatialPartial j (a.1 : ℍ))
```

The subtraction stays inside each bracket. `ellipticRegularPartDomain L`
excludes the remaining poles. It is open and contains zero;
`ellipticRegularPart_regular` proves the canonical extension smooth and both
left and right regular there. Its agreement with wp−G_j follows from
`ellipticRegularPart_eq_sub`. Values assigned to singular total functions in
Lean play no role in establishing smoothness of this remainder through zero.

The final theorem applies to **any** smooth extension satisfying the written
conditions. It does not require the reader to select this particular series
representation. `ellipticRegularPart_extension_eqOn` proves that every continuous
extension agrees with the canonical remainder on the intersection of their
neighborhoods. Continuity fixes the value at zero from the punctured limit;
equality on an open neighborhood then fixes all derivatives. Regularity of h
is not needed as an additional hypothesis for this identity; E1's smooth,
two-sided regular extension is included.

## Exact theorem

In namespace `MathResearch.Fueter`, with
`(L : Submodule ℤ ℍ) [DiscreteTopology L] [IsZLattice ℝ L]`:

```lean
theorem N1_v2 (j : Fin 3) {U : Set ℍ} (hU : IsOpen U) (h0 : (0 : ℍ) ∈ U)
    {h : ℍ → ℍ} (hh : ContDiffOn ℝ ∞ h U)
    (he : ∀ q ∈ U, q ∉ L → h q = elliptic L j q - kernelSpatialPartial j q)
    (μ : Fin 3 → ℕ) (hμ : 1 ≤ ∑ i, μ i) :
    multiIndexPartial (spatialMultiIndex μ) h 0 =
      eisensteinCoefficient L (μ + Pi.single j 1)
```

The formalization author compared the domain, positive-order restriction,
unit multi-index, derivative ordering, signs and normalization with the saved
source. This is a correspondence assessment, not independent review or a
visitor approval state. The statement and each supporting definition remain
available for readers to inspect.

## Proof and mathlib reuse

[PartialCommutation.lean](../MathResearch/Fueter/PartialCommutation.lean) uses
mathlib's symmetry of the second real Fréchet derivative. It proves that smooth
coordinate derivatives commute and that any permutation of an ordered derivative
list gives the same result on an open smooth domain. Mathlib's list permutation
and count API verifies that appending the spatial derivative j has exactly the
multiplicities of μ+ε_j. `kernelJet_spatial` connects E1's ordered derivatives
to N2's canonical multi-index convention.

[EllipticCoefficients.lean](../MathResearch/Fueter/EllipticCoefficients.lean)
reuses E1's proven calculus of subseries. Differentiating the regular part to
positive order removes the subtracted constants. At zero the resulting terms
are exactly `higherKernel (μ + Pi.single j 1) a`, whose sum is the coefficient
already defined in N2. Absolute convergence is established by the existing
mathlib-based lattice p-series theorem. Uniqueness of an extension uses mathlib's
uniqueness of limits in a Hausdorff space. Equality of derivatives on an open
set uses mathlib's local equality theorem for Fréchet derivatives.

There are no new axioms or unproved convergence, derivative-commutation,
regularity or extension-uniqueness premises. The smooth-extension hypotheses
in `N1_v2` express the object specified in the article. Its existence is already
proved by E1 and is checked explicitly in the statement-check file.
